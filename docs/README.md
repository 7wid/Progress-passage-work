## 部署与运维

从[持续部署服务器准备指南](持续部署服务器准备指南.md)开始，按阶段阅读：

1. [GHCR 发布端](CD-pull-ghcr.md)：CI、应用镜像和发布记录。
2. [服务器拉取端](CD-pull-agent.md)：安装、dry-run、初始化、单次部署、调度、暂停和恢复。
3. [CD 邮件告警与本地保留](CD-email-alert-retention.md)：systemd credential、告警测试、独立清理开关及 journal 策略。

[源码构建部署与运维](源码构建部署与运维.md)仅适用于使用根目录生产 Compose 和命名卷的新环境；不要将其初始化命令用于已有服务器的绑定目录部署。
